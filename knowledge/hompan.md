# 네이버 블로그 홈판 & 노출 알고리즘 학습 정리

> 본 문서는 7개 병렬 리서치(홈판/홈피드, C-Rank·D.I.A.·D.I.A.+, 2025-2026 최신 변화·인플루언서·AI 정책, 경제·투자 니치, 부업·부동산 니치, 자동화 기술·리스크, 온페이지 SEO)를 병합·정리한 것이다.
> **중요 전제:** 네이버는 C-Rank·D.I.A.·홈피드 랭킹의 구체적 가중치·점수식을 공식 공개하지 않는다. 아래 수치(글자수·이미지 개수·체류시간·키워드 횟수 등)는 대부분 **마케팅 업체·블로거의 관찰 기반 경험칙(추정치)**이며 공식 규격이 아니다. 파이프라인에서는 고정 상수가 아니라 **조정 가능한 파라미터(config)**로 두고 실측으로 갱신해야 한다.

## 1. 홈판이란 무엇인가 (정의 / 노출면 / 선정 원리)

### 1-1. 용어 정리 (3가지가 혼용됨 — 반드시 구분)
- **(A) 전통적 '홈판'** = PC 네이버 첫 화면의 주제판(연예판·스포츠판·경제판·자동차판 등). 과거 수동 편집 → 최근 AI 추천 확대.
- **(B) 현재 블로거들이 말하는 '홈판/홈피드 노출'** = **모바일 네이버 앱 메인 화면의 개인화 추천 피드**. 본 문서에서 "홈판"은 기본적으로 이 의미다.
- **(C) 일부 가이드(TILNOTE 등)의 '홈피드'** = '내 블로그 첫 화면(대표글·카테고리 영역)'이라는 전혀 다른 뜻.

> 파이프라인/프롬프트에 이 3개 개념을 구분하는 **용어 사전을 내장**할 것. 특히 (B)와 (C) 혼동 주의.

### 1-2. 정의와 노출면
- 홈판(홈피드)은 사용자가 **검색하지 않아도** AI가 블로그·동영상·쇼트폼을 SNS 피드처럼 밀어주는 **발견(discovery) 영역**이다.
- 검색 이력·클릭·쇼핑내역 등 개인화 신호를 반영해 **대표이미지 + 제목**을 스크롤형으로 노출한다.
- **유입 확인법:** 블로그 통계 유입경로에 `네이버 메인_모바일_홈판`으로 찍힌다. 크리에이터 어드바이저에서 '검색 유입 vs 메인(홈피드) 유입'을 분리 모니터링 가능.

### 1-3. 검색 노출 vs 홈피드 노출 (본질 차이)

| 구분 | 검색 노출 | 홈피드(홈판) 노출 |
|---|---|---|
| 트리거 | 사용자가 능동적으로 검색 | 검색 없이 AI가 자동 푸시 |
| 핵심 기준 | 키워드·SEO·C-Rank/정확도 | 클릭률 + **체류시간** + 공감·댓글·스크랩 |
| 진입 장벽 | 블로그 지수(C-Rank) 영향 큼 | **블로그 지수와 무관, 초보자도 진입 가능** |
| 지속성 | 상대적으로 안정적 | 변동성 큼, 지속 불확실 |

### 1-4. 선정 원리 — 2단계 추천 구조 (업계 재구성, 비공식)
1. **리트리버(Retriever, 후보 선정):** 구독 기반·키워드 기반·검색이력 기반·인기도 기반·소비이력 기반으로 후보군 생성. 특히 **After Search**(최근 검색 연관), **Click2Click**(최근 클릭 연관)이 실시간 관련성 축.
2. **랭커(Ranker, 순위 결정):** 클릭확률 + 만족도(체류시간) + 다양성으로 순위 산정(DCN·MDE류 모델 언급). **"클릭은 높지만 금방 이탈하는 글"은 감점**된다.

**신호 우선순위(경험칙):** 체류시간(최상위) > 클릭률 > 공감·댓글·스크랩 > 실시간 이슈 연관성. 자극적 낚시 제목은 초기 클릭은 올려도 이탈률로 역효과.

### 1-5. 편집자 선정(에디터 픽) — 별개 경로
- **'이달의 블로그'**: 매월 31개 주제에서 양질·성장 블로그를 **사람이 선정**(이달의 주제/에디터 픽/테마 블로그/루키 블로그). 알고리즘 추천이 아닌 편집 노출.
- **'피드 메이커' 제도**: 트렌디·유익한 블로거를 선정해 홈화면에 자주 노출(700명, 월 10만 포인트 + 최대 50만원 인센티브 보고 — 시점 의존적 수치).

### 1-6. 트래픽 임팩트 (과장 가능성 유의)
- 실사례로 방문자 10배 증가, 일 1만+ 방문 달성 보고. 네이버 공식 지표로 "3분기 홈피드 사용자 수 1분기 대비 22.0% 증가, 콘텐츠 클릭 수 86.0% 증가".
- **단, 성과 사례 상당수가 수익형 블로그 마케팅 업체발이라 체리피킹 가능성.** 홈판 유입에만 의존하는 전략은 리스크.

## 2. 노출 알고리즘 (C-Rank / D.I.A. / D.I.A.+ / 스마트블록)

### 2-1. C-Rank (Creator Rank, 2016~) — '출처(블로그)' 신뢰도
- 개별 글이 아니라 **블로그(출처) 자체**를 평가. 최종 순위는 **C-Rank(출처 점수) + D.I.A.(문서 점수)의 조합**.
- **3C(또는 확장 4C) 평가축:**
  - **Context(맥락):** 특정 주제 집중도·전문성 → **가장 중요.** 3개 이내 카테고리에 꾸준히 축적한 블로그가 유리. 잡블로그는 불리.
  - **Content(내용):** 개별 글의 독창성·정보량·신뢰성.
  - **Chain(연결):** 댓글·공감·스크랩·공유 등 소비/반응 신호, 이웃.
  - **(Creator):** 운영 기간·연속성·누적 콘텐츠량·외부 인용.
- C-Rank가 높으면 해당 주제 키워드에서 **신규 글도 초기 노출 가산점**을 받는다.

### 2-2. D.I.A. (Deep Intent Analysis, 2018~) — '개별 문서' 품질/경험
- 문서 단위로 검색의도 부합도 + 실제 경험·정보 깊이·고유 의견을 평가.
- 선호 문서 특징: ① **실제 체험기(직접 경험)** ② 상세·깊이 있는 정보 ③ 전문성 있는 고유 의견.
- **핵심 시사점:** C-Rank가 낮은 **신생 블로그도 D.I.A. 점수(문서 품질)가 매우 높으면 상위노출 가능** → 신규 블로그의 진입 경로.

### 2-3. D.I.A.+ — 논리 구조 + 검색의도 충족 (딥러닝)
- 문서의 **논리적 구조**(서론-본론-결론, 소제목/표/리스트)와 질의 의도(정보형/거래형/체험형) 충족을 딥러닝으로 이해.
- 잘 구조화된 정보성 롱폼 자체가 품질 신호.
- **업계 관측(비공식·미검증):** 최신 버전은 HyperCLOVA X 기반으로 맥락·정보 정확성·**이미지 원본 여부**까지 판별하고 **영상 삽입에 가산점**. → 콘텐츠에는 "업계에서는 ~로 본다" 식으로만 표기해야 하며 단정 금지.

### 2-4. 스마트블록 & 에어서치(AiRSearch, 2021~) — 상위 레이어
- **에어서치 = AI + Search.** 사용자 활동이력·취향을 반영해 **주제 단위 개인화** 결과 제공. 동일 검색어라도 사용자마다 결과가 다름.
- **스마트블록:** 하나의 검색어를 의도별로 잘게 쪼개 노출(예: '아이스아메리카노' → '칼로리' 블록 / '만들기' 블록). VIEW탭 폐지 후 UGC(블로그·카페)가 스마트블록으로 완전 통합.
- **전략:** 타깃 키워드를 실제 검색해 노출되는 **스마트블록 세부 주제를 크롤링**하고, 각 블록을 소제목/단락으로 커버하는 아웃라인 설계(롱테일 공략).

### 2-5. 저품질(노출 제한)의 실체
- **별도 '패널티 버튼'이 아님.** C-Rank·D.I.A. 점수가 종합적으로 낮아져 검색결과에서 사실상 사라지는 상태(예: 3페이지/21번째 이후로 밀림).
- **유발 신호:** 유사문서/복붙, 키워드 스터핑, 짧은 체류·빠른 이탈의 홍보성 글, 상업 링크·광고 대행 패턴, 재사용·펌 이미지, 이미지→동영상 변환 편법, 자동 공감/댓글/스크랩·트래픽 조작(어뷰징), 불법·유해 콘텐츠.
- **자가진단:** 발행 글 제목을 그대로 검색창에 넣어 검색 → 내 글이 최상단에 없으면 유사문서/금칙어/저품질 의심. 다수 글에서 반복되면 저품질 진행으로 볼 수 있음.
- **회복 여부·기간은 불확실.** "무조건 회복" 같은 단정 금지.

## 3. 2025-2026 최신 변화 & 인플루언서 & AI 콘텐츠 정책

### 3-1. 구조 대전환 (검색 → AI 추천·개인화 피드)
- **2025년 9월:** 네이버 '블로그 개편 로드맵' 공식 발표 — 검색형에서 **유튜브식 개인화 추천 플랫폼**으로 전환 명시. 2025년 6월부터 홈피드 영역 확대 A/B 테스트.
- **연관검색어 종료:** 2026년 4월 7일 공지, **4월 30일 20년 서비스 종료**. AI 브리핑(의도·맥락 기반)으로 대체.
- **AI 브리핑:** 블로그·카페·지식iN을 종합해 검색 상단에 요약 답변 제공. **약 3천만 이용, 전체 검색 쿼리 약 20% 처리.** → "키워드 반복 배치 상위노출" 방식 효력 상실, 기존 블로그 방문자 감소의 핵심 원인.
- **AI탭 정식 출시:** 2026년 6월 26일 대화형 AI 검색 전체 출시(쇼핑·플레이스·예약 연결). 2026년 7월 중하순 AI 브리핑 지면에 검색광고 도입 예정.

### 3-2. 창작자 보상 프로그램
- **네이버 메이트:** 2026년 6월 4일 베타. **AI 브리핑에 '인용된 빈도'** 기준으로 창작자 선정. 월 기본 30만원 / 우수 300만원 / 최상위 1,000만원. 연 약 200억원(5년 총 1조원 규모). → **AI가 인용할 만한 구조화·신뢰성 콘텐츠가 보상받는 구조.**
- 수치는 특정 시점 기사 기준, 조건·기간 변동 가능 → 최신 공지 재확인 필요.

### 3-3. AI 콘텐츠 정책 — "사용 자체는 미차단, 품질로 판정"
- 네이버 공식 입장: **AI 사용 여부가 아니라 콘텐츠 품질·출처 신뢰도** 기준. AI로 쓴 글도 품질 충족 시 상위노출 가능.
- 텍스트 패턴 직접 판별이 아닌 **간접지표 기반** → 단순 리라이팅으로 회피 불가.
- **AI 글이 밀리는 4대 간접지표(관찰 기반, 비공식):**
  1. **체류시간** — 핵심 답변 지연, 채우기 텍스트
  2. **재방문율** — 신뢰 부재
  3. **정보 추출성** — 구조화 부재 → AI 브리핑 인용 실패
  4. **독창성** — 중복 표현·구조 반복
- 대표 감점 요인: `이 글에서는 ~에 대해 알아보겠습니다` 식 정형 서론, 분량 늘리기용 문장.

### 3-4. 인플루언서 프로그램
- **노출 이점:** 인플루언서만 **키워드챌린지** 참여 가능. 챌린지 상위 1~3위는 통합검색 '인플루언서 참여 콘텐츠'로 **일반 블로그보다 상위 배치**. 카테고리별 전문성 인증으로 신뢰도 가점.
- **신청 조건(비공식·통설):** 공식 수치 기준 없음(네이버 명시). 통용치: 연동 채널 합산 최소 30개+ 포스팅, 최근 3개월 내 10개+ 꾸준한 발행. 심사축 ≈ 방문자 수 / 발행량 / 주제 전문성.
- 승인 사전 보장 불가. 챌린지 상위노출 대행·조작(팬 추가·조회수 등)은 어뷰징 제재 위험 → **파이프라인 편입 금지.**

## 4. 니치별 전략 — 경제 / 투자 / 부업 / 부동산

> 공통: 한 블로그 = 단일 전문 주제 집중(C-Rank Context 확보). 초기 30~50개 글을 같은 카테고리로 발행 후 확장. 애드포스트 현실 수익(공통): 일 100명 ≈ 월 2~3천원 / 300~500명 ≈ 월 1~3만원 / 1,000명+ ≈ 월 5~10만원+. 애드포스트 신청: 글 10개+ & 최근 6개월 발행이력. **연 300만원+ 시 사업자등록 검토.**

### 4-1. 경제 (재테크·경제용어)
- **핵심 키워드 유형:** 경제용어 해설, 연금/ISA 절세, 금리·시황·실적시즌 정보성. (빅키워드 단독 금지, 롱테일 우선)
- **잘 먹히는 포맷:** 정보 정리형, 용어 해설형, 데이터 인용형(KRX·금융투자협회·데이터랩 1차 출처 명시).
- **수익화:** 애드포스트(경제/금융 CPC 높음) + 증권계좌 개설·핀테크·절세상품 제휴(니치에 자연스러운 것만).
- **규제 주의:** 상대적으로 낮으나 금융투자 정보도 표현/형식에 따라 규제 경계. 사업 확대 시 유사투자자문업 신고 여부 확인.

### 4-2. 투자 (주식·ETF) — **규제 리스크 최상**
- **핵심 키워드 유형:** 'ETF·배당·연금/ISA' 같은 구체 소주제. '주식 전반'보다 좁게.
- **잘 먹히는 포맷:** 정보·비교·용어해설·과거 데이터 분석 + **직접 계산한 배당 시뮬레이션 표 / 본인 계좌 후기** 등 복붙 불가 요소 최소 1개.
- **수익화:** 애드포스트 + 증권계좌 제휴.
- **규제 주의 (반드시 파이프라인 차단):**
  - 대가 받고 종목 추천·실시간 투자전략 제시(**리딩방**) → 2024년 자본시장법 개정으로 **불법**.
  - 미신고 유사투자자문업 → 과태료 1천만원 이하.
  - 무인가 투자중개·고수익 보장 유치 → 5년 이하 징역 또는 2억원 이하 벌금.
  - **선행매매(pump-and-dump):** 특정 종목 적극 권유 직후 본인 매도 시 형사책임. 보유 종목 홍보 특히 위험.
  - **표준 면책문구 자동 삽입 필수:** "본 글은 정보 제공 목적이며 특정 종목의 투자 권유가 아닙니다. 투자 판단과 책임은 투자자 본인에게 있습니다."
  - '주식·대출·보험'은 네이버 저품질 집중 모니터링 키워드 → 제목 남발 금지(수익성과 저품질 위험 공존).

### 4-3. 부업
- **핵심 키워드 유형:** '재택부업 후기', '월30만원 부업' 등 현실 롱테일. 인기 소재(2026): 앱테크(현실 월 1~3만원), 스마트스토어 위탁판매, 쿠팡파트너스 AI 자동화, 직장인 기술 자산화.
- **잘 먹히는 포맷:** **현실적 후기 + 정산 데이터(캡처·월 수익 숫자·소요시간) + 단계별 실행법.**
- **수익화:** 애드포스트 + 쿠팡파트너스 + 스마트스토어 연계(저단가 애드포스트 단독은 한계).
- **규제 주의:** '원금보장', '확정수익', '목표 수익률 OO%', '손실 전액 환불' 등 → 유사투자자문·불법금융광고 금지(2025년 당국 105개 133건 적발). 협찬·제휴 시 **'광고/제휴' 표시 의무(뒷광고 방지).**

### 4-4. 부동산
- **핵심 키워드 유형(시의성 큼):** 전월세, 청약(분양가·청약통장 개편), 정책자금·대출(LTV/DSR·특례대출), 지역별 실거래가 분석. 신생아 특례대출 조건 등 구체 롱테일.
- **잘 먹히는 포맷:** '정책 변경 정리형', '실거래가 데이터 분석형' (검색·저장 수요 높음). 국토부·한국부동산원 1차 데이터 인용.
- **수익화:** 애드포스트 + 대출·중개 정보성 리드 제휴(반드시 '광고/제휴' 표시).
- **규제 주의:** 공인중개사법 제18조의2 + 표시광고법. **미끼매물, '단지 내 최저가·압도적 조망권' 등 근거 없는 주관적 표현, 무단 사진 사용** → 자격정지·형사처벌·민사배상. 정보성 블로그도 허위·과장 표시 규제 대상 가능. '최저가' 주장 시 실거래가 근거 제시 의무.

### 4-5. 니치 공통 시즌 트리거
- 부동산: 청약 일정, 이사철(봄·가을), 정책 발표(LTV/DSR·특례대출).
- 부업: 연초 '새해 부업', 연말정산·소득세 시즌, 명절 앞 단기부업.
- 투자/경제: 실적시즌, 금리결정, 경제용어 검색 급등 시점.

## 5. 콘텐츠 / 온페이지 SEO 규칙 (숫자 포함)

> **⚠️ 출처 간 수치 상충 존재.** 특히 글자수는 유형에 따라 크게 다르다. 고정 상수화보다 **경쟁 상위 1~5위 글의 평균값 벤치마킹**이 더 정확하다.

### 5-1. 제목
- **25자 이내** 권장(모바일 잘림 방지).
- **핵심(메인) 키워드를 맨 앞에 1회만** 배치. 동일 키워드 2회+ 반복은 스팸/패널티 위험.
- 클릭률 상승 요소: 숫자(TOP5, 3가지), 연도(2026), 문제해결/감정어(총정리·모르면 손해·후기).
- **홈피드용**은 추가로 호기심 갭·대비·역발상(예: 'AI로 PPT 오히려 더 오래 걸림').
- '무조건·최고' 등 과장·낚시 표현 지양.

### 5-2. 글자수 (유형별 상충 — 반드시 분기 처리)

| 유형 | 권장 글자수 | 근거 |
|---|---|---|
| **홈피드형** | 2,000자+ (가능하면 3,000자+) | 체류시간 확보 |
| **검색형 경쟁 키워드** | 3,000자+ 롱폼 | 전문성 인정 필요 |
| **검색형 일반** | 1,500~2,000자(공백 포함) | 실무 합의값 |
| **단순·저경쟁** | 600~800자로도 노출 사례 | 유형 상이 |
| **하한** | **300자 미만은 저품질** | 발행 차단 권장 |

> 핵심은 글자수 채우기가 아니라 **검색 의도 해결**.

### 5-3. 키워드 배치 / 밀도
- 1,500~2,000자 기준: **메인 키워드 = 제목 1회 + 본문 3~5회**(서론·소제목·결론에 분산). 첫 문단에 메인 키워드 자연 포함.
- 메인+서브 합쳐 **총 5~6개**. **키워드 밀도 약 1~2%.**
- 본문 반복 6회 초과 시 경고(스터핑 방지). 하이퍼클로바X가 문맥을 읽으므로 기계적 반복은 역효과.

### 5-4. 이미지
- **6~13장** 통용(경쟁 글 평균에 맞추는 게 더 정확). 검색 SEO 기준으로는 최소 3~5장.
- **반드시 직접 촬영/제작 원본.** 유사·펌·중복 이미지는 저품질 트리거(pHash 중복 검사 권장).
- 파일명·ALT(대체 텍스트)에 키워드 삽입, 업로드 전 압축(로딩 속도).
- **대표 썸네일:** 텍스트 최소·대비 강하게 1장. 블로그 전체 썸네일 톤 통일(브랜드 인지·CTR).

### 5-5. 영상 / 시각 요소
- 동영상·움짤·인포그래픽 혼합 시 체류시간 유리(영상 삽입 가산점은 업계 관측).
- **'이미지→동영상 변환' 편법은 저품질 원인** → 실제 영상 콘텐츠 사용.
- **클립(숏폼)** 병행: 앱 내 클립 제작 후 글에 삽입, 클립 스티커로 글 연결 → 검색+홈피드 이중 노출.

### 5-6. 소제목 / 구조
- 소제목(H2/H3) 2~4개 + 목차. **서론-본론-결론 논리 구조 강제**(D.I.A. 평가).
- **한 문단 3~4문장 이하**(홈피드형은 2~3문장으로 더 짧게).
- 요약박스·표·체크리스트로 스캔 가능하게(체류시간·D.I.A.+ 대응).

### 5-7. 태그
- **검색 순위 영향 거의 없음**(다수 의견). PC는 블로그 내 색인용, 모바일은 동일 태그 최신글 노출용.
- 글 주제 직결 키워드 **5~10개만**. 과다 금지.
- **발행 후 태그만 잦게 수정하는 것은 오히려 마이너스** 가능.

### 5-8. 발행 시간 / 빈도
- **발행 시간대는 최종 순위가 아니라 초기 유입 부스트를 좌우**(초기 유입량 최대 3배 차이 주장 — 검증 안 된 배수).
- 정보성/검색형: **화~목 오전 7~10시**(출근길 모바일 + 업무 시작 PC 검색).
- 홈피드형: **저녁 7~10시**.
- 경제/투자: 오전 7시·점심 12시·저녁 7시 슬롯.
- 라이프스타일: 토 오전 10~12시.
- **발행 빈도: 주 3~5편(또는 2~3회), '꾸준함'이 핵심.** 매일 대량 발행보다 일관성. (월 16편+ vs 5편↓ 트래픽 3.5배 차 주장 — 검증 안 된 배수)

### 5-9. 내부링크 / 소통
- 관련 이전글 내부링크 **1~3개** → 체류·페이지뷰·시리즈 재방문 유도.
- 서로이웃·댓글 응답 등 활성 블로그가 C-Rank 유리.
- 외부 백링크: 권위 사이트 소수는 도움, **상업성·스팸 링크 남발은 저품질 원인.**

### 5-10. 고유성 (D.I.A.+ 대응 최우선)
- AI 초안에 반드시 **실제 경험·수치·후기·자체 촬영 이미지**를 결합해 '유일무이한' 정보로 재가공. 무편집 자동생성 금지.
- 발행 전 유사도 검사(자사 과거 글 + 외부 웹), 발행 직후 '제목 전체 검색 → 최상단 노출' 헬스체크.

## 6. 자동화 기술 옵션 & 리스크

### 6-1. 공식 API 현황 — **합법적 자동 발행 경로 없음**
- 네이버 **글쓰기 API(openapi.naver.com/blog/writePost)는 2020년 5월 6일 종료.** 사유: 광고성 글 대량 제작. 신규 프로그래밍 방식 발행 불가.
- **함정 주의:** `naver.github.io` 개발자 가이드에 'writePost.json' 항목이 남아있으나 **갱신 안 된 아카이브**일 뿐 실제 엔드포인트는 종료. 현재 사용 가능한 블로그 오픈API는 사실상 **조회성(블로그 검색 GET)** 뿐.

### 6-2. 셀레니움/매크로 — 명백한 정책 위반, 제재 강화
- Selenium/Playwright로 로그인·발행은 기술적으로 가능하나 **네이버 운영정책상 '비정상 행위'.** 대표 오픈소스 README조차 "계정 제한·제재 발생 가능" 명시.
- **2025년 7월경부터** 댓글·공감·서로이웃 등 봇 접근 강력 차단 시작.
- **제재 강도(커뮤니티 정보, 공식 미확정):** 기본 90일 제재, 2회+ 누적 시 영구 제재 가능. 저품질 시 검색 3페이지(21번째)+로 밀림.
- 상용 '완전 자동화 툴'('딸깍 프로그램' 등)의 '안전' 주장은 **검증 안 됨** — 대부분 동일한 브라우저 자동화 의존으로 동일 리스크를 사용자에게 전가.
- **제재 기준은 비공개** → '안전 임계값' 보장 불가. 오늘 통하는 방법이 내일 제재될 수 있음.

### 6-3. 합법 영역
- **네이티브 예약발행:** 네이버 에디터 기본 기능. 사람이 직접 작성·예약하면 자동화 제재 대상 아님. 발행 시점 분산에 활용.
- **자동화의 가치는 '발행'이 아니라 '생성·기획·검수 보조'에 둘 것.**

### 6-4. Human-in-the-loop 권장 설계
> **아키텍처 원칙: 생성(자동) → 검수(사람) → 발행(사람/네이티브 예약).** '자동 로그인 후 자동 발행' 단계는 설계에서 **배제**. 자동화 경계선을 발행 직전에 둔다.

- **초안 배달 자동화로 우회:** 생성 글을 이메일/Notion/Google Docs/Slack로 자동 전달 → 사람이 복붙·다듬어 발행. 발행 행위 자체를 사람이 하므로 봇 탐지 표면 없음.
- **자격증명 미저장 원칙:** 자동 발행을 안 하므로 네이버 ID/PW·세션 쿠키를 파이프라인에 저장하지 않음(유출 리스크 제거).
- **휴먼 게이트:** 각 글에 '사람 승인' flag 없이는 다음 단계 진행 불가.
- **계정 분리:** 어떤 자동화 실험도 수익/메인 계정에서 금지(테스트도 소모용 계정 한정).

## 7. 파이프라인 설계 시사점 (체크리스트)

### 7-1. 수집·기획 단계
- [ ] **트렌드 크롤러(앞단):** 매일 네이버 실시간 이슈/데이터랩 키워드 수집(홈피드 After Search 공략).
- [ ] **키워드 도구 연동:** 검색광고 키워드도구·키워드마스터·판다랭크에서 (검색량, 총문서량, 경쟁도) 수집 → **'검색량↑·문서량↓' 롱테일만 자동 큐잉.** 빅키워드 단독 타깃 금지.
- [ ] **스마트블록 크롤링:** 타깃 키워드의 세부 블록 주제를 수집해 아웃라인에 반영.
- [ ] **경쟁 벤치마크:** 상위 1~5위 글의 평균 글자수·이미지 수·소제목 수를 크롤링 → 생성 목표값으로 사용(고정 상수 대신).

### 7-2. 콘텐츠 생성 단계 (하드 룰)
- [ ] **intent 태그 필수 부여:** `search`(키워드·정보밀도·구조화) vs `homefeed`(이슈연결·감정후킹·반전제목) → 다른 템플릿·발행시간 적용.
- [ ] **니치별 템플릿 분리:** 경제/투자(정보정리·데이터분석) / 부업(현실후기·정산데이터·단계별) / 부동산(정책정리·실거래가분석·전월세가이드). 각 템플릿에 **Q&A 소제목 구조 + 1차 데이터 필드 + 요약박스** 강제(AI 브리핑 인용 대비).
- [ ] **제목 규칙:** 25자 이내 + 메인 키워드 맨 앞 1회 + (숫자/연도) + 감정·문제해결어. 후보 3개 생성 후 길이·키워드 위치 자동 검증.
- [ ] **글자수 분기:** homefeed 2,000자+ / 검색 경쟁 3,000자+ / 검색 일반 1,500~2,000자 / **300자 미만 발행 차단.**
- [ ] **키워드 밀도 검사:** 메인 제목 1회 + 본문 3~5회, 밀도 1~2%, 6회 초과 경고.
- [ ] **구조 검사:** 소제목 2~4개 + 목차, 문단 3~4문장 이하(홈피드 2~3문장), 서론-본론-결론.
- [ ] **고유성 슬롯 강제:** 실경험 1문단 + 구체 수치·날짜·금액 + 표/체크리스트 1개 필수. 순수 AI 텍스트만으로는 발행 불가.
- [ ] **금지 문구 필터:** 정형 서론(`~에 대해 알아보겠습니다`)·채우기 문장·과장어(무조건·최고) 자동 제거.

### 7-3. 품질·중복 게이트 (필수 체크포인트)
- [ ] **유사문서 검사:** 발행 전 (외부 웹 + 자사 과거 글) 텍스트 유사도(코사인/자카드) 임계 초과 시 자동 리라이트.
- [ ] **이미지 중복 검사:** pHash로 펌·재사용 이미지 차단. 원본 6~13장(검색형 3~5장+), ALT·파일명 키워드.
- [ ] **팩트체크 단계:** 정책·세금·보험·의료·부동산 수치는 웹 검증 + 공식 출처 링크 1개+ 하단 삽입.
- [ ] **발행 직후 헬스체크:** 제목 전체 검색 → 최상단 노출 여부 자동 확인, 실패 시 알림·재작성 트리거.

### 7-4. 컴플라이언스 필터 (최우선 — 자동 차단)
- [ ] **투자 금지어:** 종목명 + 매수/목표가/추천/보장/리딩/수익률 확정 표현 → 정규식·분류기 탐지 후 차단 또는 인간 검수 라우팅.
- [ ] **부업 금지어:** 원금보장·확정수익·목표수익률%·손실 전액 환불.
- [ ] **부동산 금지어:** 최저가·급매 확정·시세차익 보장·조망권 최고·확정 프리미엄(근거 데이터 없으면 표현 자체 제거).
- [ ] **면책문구 자동 삽입:** 투자/종목 언급 글에 표준 disclaimer append.
- [ ] **광고/제휴 표시 자동화:** 쿠팡파트너스·부동산 제휴 링크 포함 글에 '광고/제휴' 고지 자동 삽입(뒷광고 규제).
- [ ] **민감 키워드 정책 테이블:** 주식·대출·보험·병원·다이어트 등 저품질 모니터링 키워드 제목 남발 스코어링·경고.

### 7-5. 발행·계정 관리
- [ ] **자동 발행 배제:** 최종 단계는 '초안 배달 + 사람 발행/네이티브 예약'. 자격증명·세션 미저장.
- [ ] **휴먼 승인 flag** 없이 발행 불가.
- [ ] **발행 스케줄러:** 검색형 화~목 오전 7~10시 / 홈피드형 저녁 7~10시. 주 3~5편 상한, 최소 간격 유지(대량 동시 발행 = 어뷰징 신호).
- [ ] **계정별 주 카테고리 lock:** 주제 이탈 시 경고(C-Rank Context 보호, 잡블로그화 방지). 다주제는 계정 분리.
- [ ] **신규 계정 램프업:** 초기 3~6개월은 민감 키워드 보수적, 발행량보다 품질 우선. 인플루언서 노림 시: 3개월·월 10개+·단일주제·누적 30개+ 후 신청.
- [ ] **어뷰징 원천 금지:** 자동 공감/댓글/스크랩 매크로, 대량 백링크, 상업 링크 자동 삽입, 인위적 트래픽 급증(저품질·계정 사망 리스크).

### 7-6. 성과 측정 (KPI 재정의)
- [ ] **KPI를 '검색 순위'에서 재정의:** 평균 체류시간, 홈판 유입 비중, 공감·댓글·스크랩률, 재방문율, AI 브리핑 인용 여부.
- [ ] **유입경로 분리 수집:** `네이버 메인_모바일_홈판` vs 검색 유입을 3~7일 주기로 로깅.
- [ ] **A/B 개선 루프:** 클릭률 낮으면 제목 교체, 체류·반응 낮으면 본문 리디자인, 반응 좋으면 시리즈화.
- [ ] **리프레시 잡:** 상위 글은 3~6개월 주기로 수치·정책 최신화(수정일 갱신) → 재노출.

### 7-7. 확장·감시
- [ ] **산출물 확장:** '블로그 글 + 숏폼(클립) 스크립트' 세트로 홈피드 노출 다변화.
- [ ] **AI 브리핑 인용형 유형 추가:** 명확한 질문-답변 문단, 정의·조건·수치 구조화(네이버 메이트 겨냥).
- [ ] **정책 변화 감시 루틴:** 네이버 검색블로그·공식 공지·AI 브리핑/AI탭/메이트 업데이트 정기 모니터링(2026년에도 광고 도입 등 변동 지속).

## 부록: 리스크·불확실성 요약 (정직한 한계)

1. **알고리즘 세부는 전부 비공식.** 리트리버/랭커·After Search·Click2Click·DCN/MDE·D.I.A.+ v3·HyperCLOVA X 이미지 판별 등은 유료강의·마케터의 추정·재구성. 콘텐츠에 단정 대신 "업계에서는 ~로 본다" 표기.
2. **수치 상충 상시.** 글자수(600~800 vs 1,500~2,000 vs 3,000+), 이미지 개수, 체류시간 등은 유형·주제·경쟁도에 따라 다름. 단일 규칙 맹신 금지, 경쟁 벤치마킹 우선.
3. **성과 주장 과장 가능.** '방문자 10배', '일 1만+', '트래픽 3배/3.5배', 수익 배수는 마케팅 업체발 체리피킹 가능성. 실측으로 재검증.
4. **자동화 자체가 최대 리스크.** 대량 자동생성·유사문서 양산·기계적 발행은 네이버 어뷰징/저품질 정책 직접 대상. 원본성·품질 게이트 없는 자동화는 계정 리스크를 키움.
5. **규제는 실제 법적 리스크.** 투자(자본시장법·유사투자자문)·부동산(공인중개사법·표시광고법)·부업(불법금융광고) 위반은 형사·행정 제재. 파이프라인이 위반 문구를 생성하지 않도록 필터링 필수.
6. **정책 급변 중.** 연관검색어 폐지·AI 브리핑·AI탭·메이트·AI 브리핑 광고 등 2025~2026 급변. 본 문서도 수개월 내 재검증 필요.
7. **출처 편향.** 다수가 SEO 대행·강의 판매·수익형 블로그(상업적 이해관계). 일부 원문은 403/404 차단으로 검색 스니펫 의존. 실제 운영 데이터로 교차검증 권장.
