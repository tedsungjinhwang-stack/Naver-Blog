## 유튜브 쇼핑 쇼츠, 문턱이 확 낮아졌음

조회수만 보고 유튜브 하던 시절은 지난 것 같습니다. 요즘은 쇼핑 제휴 쪽이 더 현실적이라길래 직접 해보고 정리해봤습니다.

먼저 이 글에는 제휴 관련 내용이 포함되어 있고, 제휴 프로그램을 통해 제품을 소개하면 판매액의 일정 비율을 수수료로 받는 구조임을 미리 밝힘.

유튜브 쇼핑 쇼츠가 뭐냐면, 내 영상에 남의 제품을 태그해두고 시청자가 그걸 눌러 사면 수수료를 받는 구조임. 내가 물건을 떼오거나 재고를 쌓을 필요가 없음. 쇼츠·일반 영상·라이브 전부 태그를 붙일 수 있음.

핵심은 참여 조건이 낮아졌다는 점임.

| 항목 | 내용 |
| --- | --- |
| 구독자 | 500명 이상 (기존 1,000명에서 완화) |
| 영상 | 최근 90일간 공개 영상 3개 이상 |
| 유튜브 수수료 | 0원 |
| 제휴 수수료 | 상품·브랜드별 상이, 평균 15% 안팎으로 알려짐 |

구독자 1,000명은 꽤 먼 벽인데 500명이면 얘기가 다름. 쇼츠로 몇 개만 터져도 닿을 수 있는 숫자임. 이게 요즘 유튜브 쇼핑 쇼츠가 부업으로 자주 언급되는 이유인 듯.

## 시작하려면 뭘 해야 하나

절차 자체는 복잡하지 않음.

1. 채널이 조건(구독자 500명 + 90일 내 영상 3개)을 충족하는지 확인
2. 유튜브 스튜디오에서 수익 창출 → 쇼핑 항목으로 들어가 제휴 프로그램 신청
3. 제휴사 계정 연동 (쿠팡을 비롯해 올리브영·컬리·오늘의집 등 국내 브랜드가 참여 중)
4. 영상 업로드하면서 소개할 제품을 태그
5. 정산 내역은 스튜디오에서 확인

여기서 놓치기 쉬운 게 있음. **광고 표시임.** 제휴 수수료를 받고 제품을 소개하면 광고라는 걸 반드시 밝혀야 함. 유튜브가 '유료 프로모션 포함' 표시를 자동으로 붙여주긴 하는데, 그것만 믿지 말고 영상 설명란이나 말로도 "제휴 링크가 포함되어 있다"고 밝히는 게 안전함. 안 지키면 콘텐츠나 계정에 조치가 들어올 수 있음.

## 실제로 해보니 달랐던 것

여기서부터는 내가 직접 돌려보고 느낀 부분임. 숫자는 각자 채널마다 다르니 참고만.

내 경우 [기간: OO개월] 동안 쇼츠 [OO개]를 올렸고, 누적 조회수는 [OO만 회], 제휴 수익은 [OO원] 정도 나왔음. 월로 환산하면 [OO원] 수준임.

체감상 가장 크게 어긋났던 건 **조회수와 수익이 비례하지 않는다**는 점임. 조회수가 잘 나온 영상보다, 살 마음 먹고 들어온 사람이 보는 영상이 훨씬 돈이 됐음. 전환 구조를 뜯어보면 이렇게 됨.

| 단계 | 내 수치 | 메모 |
| --- | --- | --- |
| 조회수 | [OO회] | 많다고 좋은 게 아님 |
| 상품 클릭 | [OO회] | 조회수 대비 [OO%] |
| 실제 구매 | [OO건] | 클릭 대비 [OO%] |
| 수수료 | [OO원] | 객단가 × 수수료율 |

그래서 조회수를 늘리는 것보다 **구매 의도가 있는 시청자를 데려오는 게** 훨씬 효율이 좋았던 것 같음. 예를 들어 "○○ 써보니" 같은 후기형이, 단순 재미형보다 클릭률이 높게 나왔음.

또 하나, 객단가가 낮은 제품은 아무리 많이 팔려도 수수료가 얼마 안 됨. 1만 원짜리 물건을 수수료 15%로 100개 팔아야 15만 원임. 반대로 객단가가 높으면 몇 건만 나와도 금액이 달라짐. 다만 비싼 물건일수록 잘 안 팔리니 이건 균형 문제인 듯.

숫자로 비교하면 더 분명해짐. 같은 15% 수수료라도 객단가에 따라 필요한 판매 건수가 이렇게 갈림.

| 객단가 | 건당 수수료 | 월 20만원 만들려면 |
| --- | --- | --- |
| 1만원 | 1,500원 | 약 134건 |
| 3만원 | 4,500원 | 약 45건 |
| 10만원 | 1.5만원 | 약 14건 |

134건과 14건은 체감이 완전히 다름. 그래서 나는 처음에 저가 생활용품 위주로 가다가, 중간 가격대로 옮겨봤음. 물론 가격이 올라가면 구매 결정이 신중해져서 전환율은 떨어짐. 이 둘을 곱한 값이 결국 수익이라, 어느 지점이 최적인지는 채널마다 직접 찾아봐야 하는 듯.
